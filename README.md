# Kota Fresh Veggie — Android Project

This is the Android Studio project version of the working Modern Fresh prototype.

## Current demo features
- Home screen
- Fruits & vegetables catalogue
- Search
- Add to cart and quantity controls
- Checkout
- Online payment / Cash on Delivery selection
- Order placement demo
- Order tracking demo
- Profile screen

## Build
Open this folder in Android Studio, let Gradle sync, then:
Build > Build Bundle(s) / APK(s) > Build APK(s)

The current project is a UI/prototype. Real online payments, login, database,
push notifications, admin panel and delivery operations still need backend
integration before production use.
